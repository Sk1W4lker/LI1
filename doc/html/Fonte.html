Description

O texto vetorial do Gloss não permite saber a largura de uma frase, o que impede de a centrar. Este módulo define um pequeno tipo de letra de píxeis (5 por 7), em que cada carácter é desenhado com retângulos e todas as letras têm a mesma largura. Suporta letras maiúsculas, algarismos e alguma pontuação.
