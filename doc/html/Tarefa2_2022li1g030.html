Description

Módulo para a realização da Tarefa 2 do projeto de LI1 em 2022/23.

A função estendeMapa acrescenta uma nova linha ao topo de um mapa. A linha é construída célula a célula e, em cada passo, só são usados obstáculos devolvidos por proximosObstaculosValidos, pelo que o resultado respeita sempre as restrições da Tarefa 1. Além de válida, a linha é pensada para ser jogável: os rios têm sempre troncos, as estradas têm intervalos entre carros e a relva nunca fecha o caminho ao jogador.

Funções principais

estendeMapa :: Mapa -> Int -> Mapa Source #

Acrescenta uma nova linha válida ao topo do mapa.

O inteiro recebido é usado como semente de um gerador pseudo-aleatório: a mesma semente aplicada ao mesmo mapa produz sempre a mesma linha.

Assume-se que o mapa dado é válido; nesse caso o mapa devolvido também o é.

proximosTerrenosValidos :: Mapa -> [Terreno] Source #

Lista os terrenos que podem ser usados numa nova linha no topo do mapa, todos com velocidade 0. Um tipo de terreno deixa de ser válido quando o topo do mapa já tem o número máximo de linhas seguidas desse tipo.

>>> proximosTerrenosValidos (Mapa 2 [])
[Rio 0,Estrada 0,Relva]

proximosObstaculosValidos :: Int -> (Terreno, [Obstaculo]) -> [Obstaculo] Source #

Lista os obstáculos que podem continuar uma linha ainda incompleta, dada a largura do mapa e a linha construída até ao momento (da esquerda para a direita).

  • Se a linha já está completa, não há obstáculos possíveis.
  • Nenhum é sempre possível numa linha incompleta.
  • O obstáculo próprio do terreno só é possível se não ultrapassar o seu comprimento máximo e se não deixar a linha sem nenhum espaço livre. Na última célula conta-se também com os obstáculos do início da linha, porque a linha é circular.
>>> proximosObstaculosValidos 10 (Rio 1, [])
[Nenhum,Tronco]
>>> proximosObstaculosValidos 2 (Estrada 1, [Carro, Nenhum])
[]

Geração de uma linha

geraTerreno :: Mapa -> StdGen -> (Terreno, StdGen) Source #

Escolhe o tipo de terreno da nova linha entre os terrenos válidos. As estradas são ligeiramente mais prováveis do que os rios e a relva.

geraVelocidade :: [(Terreno, [Obstaculo])] -> Terreno -> StdGen -> (Terreno, StdGen) Source #

Atribui uma velocidade ao terreno escolhido.

  • A relva não tem velocidade.
  • Os rios têm velocidade 1 ou 2 e correm no sentido oposto ao do rio imediatamente abaixo, caso exista.
  • As estradas têm velocidade entre 1 e 3, em qualquer sentido.

geraLinha :: Int -> Terreno -> StdGen -> [Obstaculo] Source #

Gera os obstáculos de uma linha com a largura dada.

A linha é construída alternando grupos de obstáculos com intervalos livres, cujos comprimentos são sorteados de acordo com o terreno. Antes de colocar cada obstáculo confirma-se que ele pertence a proximosObstaculosValidos; caso contrário, começa-se um intervalo livre.

abreCaminho Source #

Arguments

:: [Obstaculo]

-> [Obstaculo]

linha nova

-> [Obstaculo] 

Garante que uma linha de relva colocada por cima de outra linha de relva não fecha o caminho.

Para cada grupo de espaços livres da linha de baixo tem de existir, pelo menos, um espaço livre imediatamente acima. Quando isso não acontece, a árvore por cima do meio do grupo é removida. Assim, de qualquer espaço livre da linha de baixo é sempre possível chegar à linha de cima.

>>> abreCaminho [Arvore, Nenhum, Nenhum, Arvore] [Nenhum, Arvore, Arvore, Nenhum]
[Nenhum,Arvore,Nenhum,Nenhum]
