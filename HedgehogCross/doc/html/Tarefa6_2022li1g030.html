Description

Módulo para a realização da Tarefa 6 do projeto de LI1 em 2022/23.

Este módulo contém o estado da aplicação e toda a lógica que o faz evoluir: a reação ao teclado (reageEvento) e a passagem do tempo (reageTempo). Todas as funções são puras. Sempre que é preciso interagir com o exterior (gravar o jogo, sair, ...) devolve-se um Efeito, que é executado pelo módulo principal. O desenho do estado está no módulo Desenho.

Como o tempo funciona

As tarefas anteriores descrevem um jogo discreto, em que os obstáculos saltam de célula em célula. Para o jogo correr de forma fluida, o estado guarda uma fase contínua. Uma linha com velocidade v percorre |v| células por cada unidade de fase, uma célula de cada vez (passosLinha), e cada um desses passos é feito pela função animaJogo da Tarefa 3. Entre dois passos, o desenho desloca os obstáculos uma fração de célula (desvioLinha), o que dá a ilusão de movimento contínuo sem alterar as regras do jogo.

O deslize do mapa segue a mesma ideia: deslize é a fração de linha já percorrida e, sempre que chega a 1, é chamada a função deslizaJogo da Tarefa 5.

moveJogador :: Direcao -> Estado -> (Estado, Maybe Efeito) Source #

Move o jogador uma célula na direção dada, durante um jogo.

O movimento é calculado por animaJogo sobre um mapa com os obstáculos parados, pelo que respeita as regras da Tarefa 3 (as árvores e os limites do mapa travam o jogador). Um movimento que levasse o jogador para fora do mapa é ignorado. Subir uma linha nova aumenta a pontuação. Se o jogador saltar para a água ou para cima de um carro, o jogo termina.

Tempo

reageTempo :: Float -> Estado -> (Estado, Maybe Efeito) Source #

Faz avançar o estado um intervalo de tempo (em segundos).

Durante o jogo, movem-se os obstáculos e o mapa desliza (passoJogo). No menu inicial apenas os obstáculos se movem, como pano de fundo. Na pausa e depois de perder, o jogo fica parado.

passoJogo :: Float -> Estado -> (Estado, Maybe Efeito) Source #

Um passo do jogo: move os obstáculos, faz deslizar o mapa e verifica, depois de cada uma destas etapas, se o jogador perdeu.

avancaObstaculos :: Float -> Float -> Jogo -> Jogo Source #

Move os obstáculos do jogo entre duas fases, usando animaJogo.

Cada linha recebe temporariamente como velocidade o número de células que tem de percorrer neste intervalo (passosLinha), normalmente 0 ou 1. A função animaJogo trata de mover os obstáculos, de arrastar o jogador que esteja em cima de um tronco e de parar os carros que o atropelem. No fim, repõem-se as velocidades originais.

Avançar uma unidade de fase equivale a uma chamada de animaJogo com a jogada Parado.

passosLinha :: Velocidade -> Float -> Float -> Int Source #

Número de células que uma linha com a velocidade dada percorre entre duas fases. O passo dá-se quando o obstáculo, no seu movimento contínuo, vai a meio caminho entre duas células.

>>> passosLinha 2 0 1
2
>>> passosLinha 1 0.2 0.4
0
>>> passosLinha (-1) 0.4 0.6
1

desvioLinha :: Terreno -> Float -> Float Source #

Desvio (em células, entre -0.5 e 0.5) com que os obstáculos de uma linha devem ser desenhados em relação à sua posição no mapa, para que o movimento pareça contínuo. É positivo para a direita.

duracaoPasso :: Int -> Float Source #

Segundos que uma linha de velocidade 1 demora a avançar uma célula. Diminui com a pontuação, o que torna o jogo progressivamente mais rápido.

velocidadeCamara :: Estado -> Float Source #

Velocidade a que o mapa desliza, em linhas por segundo.

Há uma velocidade mínima, que aumenta com a pontuação e obriga o jogador a avançar. Quando o jogador passa acima da linhaAlvo, a câmara acelera para o acompanhar, abrandando à medida que se aproxima dele.

causaDerrota :: Jogo -> Causa Source #

Motivo pelo qual um jogo terminou. Só faz sentido para jogos em que jogoTerminou é verdadeiro.
