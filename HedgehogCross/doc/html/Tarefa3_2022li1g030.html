Description

Módulo para a realização da Tarefa 3 do projeto de LI1 em 2022/23.

A função animaJogo calcula o estado seguinte de um jogo: primeiro move o jogador, de acordo com a jogada, e depois move os obstáculos de cada linha, de acordo com a velocidade do terreno. Segue as regras do enunciado da Fase 1 e os esclarecimentos da adenda da Fase 2 (atropelamentos e movimentos em cima de troncos).

Função principal

animaJogo :: Jogo -> Jogada -> Jogo Source #

Anima um jogo: move o jogador segundo a jogada dada e, em seguida, os obstáculos de todas as linhas. As dimensões do mapa nunca se alteram.

>>> animaJogo (Jogo (Jogador (1,0)) (Mapa 3 [(Estrada 2, [Carro, Nenhum, Nenhum])])) Parado
Jogo (Jogador (1,0)) (Mapa 3 [(Estrada 2,[Nenhum,Carro,Nenhum])])

Movimento do jogador

animaJogador :: Jogo -> Jogada -> Jogador Source #

Calcula a nova posição do jogador.

  • Fora de um tronco, o jogador move-se 1 unidade na direção pedida, exceto se isso o levasse para fora do mapa ou para cima de uma árvore.
  • Em cima de um tronco, um movimento vertical leva o jogador diretamente para a linha de cima ou de baixo, sem acompanhar o tronco.
  • Em cima de um tronco, um movimento horizontal equivale a mover primeiro o tronco e depois o jogador.
  • Se o jogador ficar parado (ou se o seu movimento for impedido) em cima de um tronco, acompanha o movimento do tronco, podendo assim sair do mapa.

celula :: Mapa -> Coordenadas -> Maybe (Terreno, Obstaculo) Source #

O terreno e o obstáculo existentes numa posição do mapa, ou Nothing se a posição estiver fora do mapa.

>>> celula (Mapa 2 [(Relva, [Nenhum, Arvore])]) (1, 0)
Just (Relva,Arvore)

posicaoLivre :: Mapa -> Coordenadas -> Bool Source #

Indica se o jogador se pode mover para uma posição: tem de pertencer ao mapa e não ter uma árvore.

Movimento dos obstáculos

animaLinha :: Jogador -> Int -> (Terreno, [Obstaculo]) -> (Terreno, [Obstaculo]) Source #

Move os obstáculos de uma linha, sabendo a posição (já atualizada) do jogador e o índice da linha.

Os rios e as estradas rodam os seus obstáculos tantas unidades quanto a sua velocidade. A exceção é a estrada onde o jogador se encontra: aí os carros avançam uma unidade de cada vez e param no momento em que o atropelam (moveCarros).

roda :: Int -> [a] -> [a] Source #

Roda uma lista de forma circular: para a direita se o número for positivo e para a esquerda se for negativo. Os elementos que saem por um lado reaparecem no lado oposto.

>>> roda 1 [Carro, Nenhum, Nenhum]
[Nenhum,Carro,Nenhum]
>>> roda (-1) [Carro, Nenhum, Nenhum]
[Nenhum,Nenhum,Carro]

moveCarros :: Int -> Velocidade -> [Obstaculo] -> [Obstaculo] Source #

Move os carros da estrada onde está o jogador, dada a abcissa do jogador e a velocidade da estrada.

Os carros avançam uma unidade de cada vez. Se, em algum momento (incluindo antes do primeiro passo), houver um carro na posição do jogador, o movimento de toda a linha é interrompido.

>>> moveCarros 3 3 [Carro, Nenhum, Carro, Nenhum, Nenhum, Nenhum]
[Nenhum,Carro,Nenhum,Carro,Nenhum,Nenhum]
