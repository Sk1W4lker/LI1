Description

Transforma o estado da aplicação (Tarefa6_2022li1g030) numa imagem do Gloss.

Tudo é desenhado com formas geométricas, sem ficheiros de imagem, numa tela virtual de 1600 por 900 unidades em que cada célula do mapa mede 100. No fim, a tela é ampliada ou reduzida para caber na janela, qualquer que seja o seu tamanho.

Função principal

desenha :: Estado -> Picture Source #

Desenha o estado completo: o mundo, o ecrã atual por cima e, à volta, umas faixas pretas que escondem o que fica fora da tela quando a janela não tem a mesma proporção.

Mundo

desenhaMundo :: Estado -> Picture Source #

Desenha o mapa e o jogador. Os terrenos ficam por baixo, depois os obstáculos e por fim o jogador, exceto quando foi atropelado: nesse caso fica debaixo do carro.

desenhaTerreno :: Float -> Float -> (Terreno, [Obstaculo]) -> Maybe Terreno -> Picture Source #

Desenha o chão de uma linha, dados o relógio (para animar a água), a ordenada do centro da linha, a linha e o terreno da linha imediatamente abaixo (para pintar os traços entre duas faixas de estrada).

desenhaObstaculos :: Float -> Float -> (Terreno, [Obstaculo]) -> Picture Source #

Desenha os obstáculos de uma linha, dadas a fase do movimento e a ordenada do centro da linha.

Cada sequência de troncos ou de carros é desenhada como um único objeto comprido, deslocado de desvioLinha para o movimento parecer contínuo. Cada objeto é desenhado também uma largura de mapa à esquerda e à direita, para que apareça de um lado enquanto desaparece do outro.

sequencias :: [Obstaculo] -> [(Int, Int)] Source #

Sequências de obstáculos de uma linha, cada uma com a coluna onde começa e o seu comprimento. A linha é circular: uma sequência que chega ao fim da linha continua no início.

>>> sequencias [Tronco, Nenhum, Tronco, Tronco]
[(2,3)]

veiculo :: Velocidade -> Int -> Picture Source #

Um veículo visto de cima, centrado na origem, dadas a velocidade da estrada e o seu comprimento (em células). Fica virado para o lado para onde se desloca. Com uma célula é um carro; com mais, é um camião com a carga atrás.
